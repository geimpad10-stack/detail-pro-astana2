# Detail Pro Astana — система управления детейлинг-центром

Расширенная версия сайта Detail Pro Astana с онлайн-записью, личным кабинетом, админ-панелью, складом и аналитикой.

## Стек

- **Frontend:** React 18 + Vite + React Router + Framer Motion
- **Backend:** Express (Node.js)
- **Хранение:** JSON-файл (`server/data/db.json`) с атомарной записью  
  (легко заменить на SQLite/PostgreSQL/Supabase)

## Быстрый старт

```bash
cd detail-pro-astana
npm install
npm run dev
```

Откроется:
- Frontend: http://localhost:5173
- API: http://localhost:3001

Или по отдельности:
```bash
npm run server   # API на :3001
npm run client   # Vite на :5173
```

## Реализованные функции

### Клиент
- [x] Онлайн-запись с календарём и проверкой свободных слотов (серверная)
- [x] Конструктор стоимости (класс авто × тариф + доп. услуги)
- [x] Регистрация / вход / выход
- [x] Личный кабинет: история заказов, статусы, отмена
- [x] Отзыв после визита (оценка 1–5 + текст; показ на главной)
- [x] Уникальный номер заказа

### Админ / Владелец (`/admin`)
- [x] Дашборд: сегодня, в работе, выручка, популярные услуги, низкий остаток
- [x] Управление заказами (смена статусов)
- [x] Список услуг и тарифов + добавление / редактирование в админке
- [x] Сотрудники + добавление / редактирование
- [x] Склад материалов + приход/списание + история движений
- [x] Автосписание материалов при статусе «Выдана»
- [x] Список клиентов
- [x] Аналитика (выручка, средний чек, по услугам)
- [x] Настройки рабочих часов и слотов

### Безопасность
- JWT-авторизация
- Роли: client / staff / admin / owner
- Проверка прав на сервере
- Защита от двойного бронирования (повторная проверка при записи)
- Снимок цен в заказе (изменение тарифа не затрагивает старые заказы)

## Переменные окружения (опционально)

Создайте `.env` в корне:

```
JWT_SECRET=ваш-секретный-ключ
PORT=3001
```

## Что ещё можно подключить

- Telegram / WhatsApp уведомления (архитектура готова, нужны токены)
- Онлайн-оплата (Kaspi / CloudPayments и т.п.)
- Миграция БД на PostgreSQL / Supabase
## Production

```bash
npm run build
NODE_ENV=production npm run server
```

Сервер раздаёт `dist/` и API на одном порту.
